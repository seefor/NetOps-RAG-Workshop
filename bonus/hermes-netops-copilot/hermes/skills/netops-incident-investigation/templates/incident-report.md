# Incident Brief

## Scope

Affected service, sites, devices, and question.

## Evidence Used

### Retrieved Knowledge

For every source include:

- source label / path
- source type
- lifecycle or authority metadata
- relevant fact

### Read-Only Operational Evidence

For every tool result include:

- exact tool name
- device or scope
- observation timestamp when supplied
- observed fact

## Documented Intent

State what approved sources say should exist or should happen.

## Observed State

State only what the read-only state tools establish.

## Conflicts and Uncertainty

Identify stale, rejected, conflicting, missing, or lower-authority evidence.

## Most Likely Cause

Give the strongest supported explanation and explicitly distinguish it from hypotheses.

## Safe Next Steps

List read-only validation and change-controlled recommendations. Do not claim that any production action was performed.

## Sources and Tools

List every retrieved source and exact tool result used in the brief.
