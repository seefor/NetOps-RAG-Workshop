# Network Configuration Standards

Production devices require unique hostnames, managed NTP, centralized logging, SSH version 2 or stronger management access, interface descriptions on routed and uplink ports, and documented routing policy. Plaintext secrets must not be stored in examples, tickets, or knowledge documents. Configuration validation must use deterministic tooling when exact compliance is required.
