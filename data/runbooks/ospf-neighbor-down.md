# OSPF Adjacency Down

Check interface state, IP subnet alignment, area, hello/dead timers, MTU, authentication, network type, passive-interface settings, and duplicate router IDs. Compare both ends before recommending change. For point-to-point links, verify both ends use compatible network types. Review recent cost or interface changes. Avoid resetting the process until evidence is captured.
