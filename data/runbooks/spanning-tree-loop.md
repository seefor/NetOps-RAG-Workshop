# Spanning Tree Instability

Capture topology-change counters, root bridge identity, blocked ports, and recent interface transitions. Look for unapproved switches, missing BPDU Guard, incorrect root priority, or a trunk connected to an access port. Do not disable spanning tree. Isolate the suspected loop only after confirming the impact path and approval.
