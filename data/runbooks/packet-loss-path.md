# Packet Loss Along a Network Path

Define source, destination, protocol, time window, and expected path. Compare loss from multiple observation points. Correlate interface counters, queue drops, routing changes, latency, and application behavior. Treat ICMP rate limiting separately from application packet loss. Do not assume the hop that stops replying is the failing hop.
