# Network Incident Triage

Start with scope, impact, time, symptoms, affected sites, affected services, and recent changes. Create a timeline. Separate observed facts from hypotheses. Use read-only validation first. Record source evidence and assign an incident severity according to policy. Escalate early when blast radius is unclear or customer-facing services are affected.
